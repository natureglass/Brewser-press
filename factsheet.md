# Brewser — Press Fact Sheet

> Brewser is a web runtime and app platform for devices your browser can't reach — starting with the Nintendo Switch.

Brewser is a homebrew web runtime built on a fork of TooTallNate's nx.js, extending its V8/Skia foundation with standards-compliant web APIs: WebGL1/2, WebSerial (CH340 and CP2102 adapters), WebUSB, WebBluetooth, Web MIDI, and WebNN. It ships with a curated app catalogue where every submission passes automated security scanning before publication, and the same apps run unchanged on PC and mobile. Brewser is free and built by a solo developer in the Netherlands.

## Notes for coverage

- Brewser does not run commercial Switch games, ROMs, or backups — it runs web content. Web games are welcome in the catalogue; the focus of the platform is apps and hardware tinkering. Full FAQ: https://brewser.io/faq
